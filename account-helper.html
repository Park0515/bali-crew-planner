계정 등록 도우미

사이트에서 사용할 아이디를 입력하면 Supabase에 등록할 주소를 만들어 드립니다.

  1. Supabase의 Authentication → Users → Add user → Create new user를 엽니다.
  2. Email에 위 주소를 붙여 넣고 원하는 비밀번호를 지정합니다.
  3. Auto Confirm User를 선택해 계정을 만듭니다.

사이트에서는 처음 입력한 아이디와 지정한 비밀번호만 사용하세요.

이 도우미는 주소만 계산합니다. 계정 생성이나 메일 발송은 하지 않으며 비밀번호를 입력할 필요가 없습니다.
